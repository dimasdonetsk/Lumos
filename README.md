Графік відключень світла для Windows: значок у треї, клік по ньому відкриває карточку зі статусом і графіком.

- ⚡ зелена блискавка — світло є; перекреслена жовта — планове відключення; червоний трикутник — аварійні
- велике число — скільки триває поточний стан, під заголовком — коли зміниться
- смуга графіка на сьогодні й завтра з точним часом кожної зміни, «Далі» — найближчі проміжки
- кнопка «Вимкнули / Увімкнули», якщо реальність розходиться з графіком
- два постачальники: обленерго (ДТЕК) або **Укрзалізниця** — для будинків, що живляться від мережі залізниці
- аварійні відключення: позначка «аварійні» з сайтів ДТЕК, сторінки Укрзалізниці, Telegram-канали Укренерго, ДТЕК та обленерго
- сповіщення перед відключенням і коли з’являється графік на завтра; темна і світла теми
- **EcoFlow**: заряд станції в картці, чи вистачить до світла за графіком, нагадування поставити на зарядку, коли світло є
- оновлюється сама з релізів GitHub

## Встановлення

1. Відкрий [останній реліз](https://github.com/dimasdonetsk/Lumos/releases/latest) і завантаж **Lumos-win-Setup.exe**.
2. Запусти. Windows може показати «Windows захистила ваш ПК» — **Докладніше → Виконати однаково** (програма не підписана сертифікатом).
3. Lumos встановиться у `%LocalAppData%\Lumos`, з’явиться в меню Пуск і запуститься.

Оновлення ставляться самі: програма перевіряє GitHub за 2 хвилини після запуску і далі раз на 6 годин.
Вручну — правий клік по значку → **Перевірити оновлення**. Видалити — через «Програми» в налаштуваннях Windows.

## Як випустити нову версію

Змінити `<Version>` у `src/Lumos.csproj` і запушити в `main`. GitHub Actions збере програму,
створить реліз із інсталятором і пакетом оновлення, і всі встановлені копії підтягнуть його самі.

Зібрати локально: встанови [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) і запусти `build.bat`.

## Області без графіків

Lumos показує графіки всіх областей, де їх публікують у вигляді, який програма може прочитати.
Для двох областей зараз такого способу немає:

| Область | Як публікують зараз | Що потрібно, щоб запрацювало |
|---|---|---|
| **Сумська** | API Сумиобленерго з 19.10.2026 відповідає лише їхньому власному сайту, а в новинах графік картинкою | Щоб обленерго знову відкрило API або писало графік текстом у Telegram-каналі (як Кіровоградобленерго). Обходити захист сайту Lumos не буде. |
| **Херсонська** | Графік видно лише в особистому кабінеті після входу | Щоб Херсонобленерго публікувало графік відкрито: на сайті, в Telegram чи як відкриті дані. Входити в чужі кабінети програма не може і не повинна. |

Якщо ти з однієї з цих областей і бачиш графік текстом десь у відкритому доступі (Telegram-канал, сторінка сайту),
напиши в [Issues](https://github.com/dimasdonetsk/Lumos/issues) — його можна буде підключити.
Споживачі **Укрзалізниці** мають графік у всіх областях: «Постачальник → Укрзалізниця».

## EcoFlow

Правий клік по значку → **Підключити EcoFlow…**. Є два способи:

1. **Ключі розробника** (офіційно). Зареєструйся на [developer-eu.ecoflow.com](https://developer-eu.ecoflow.com) тим самим акаунтом, що й у застосунку EcoFlow, натисни «Become a Developer», дочекайся листа про схвалення, у розділі Security створи Access Key і Secret Key і встав їх у Lumos. Станція підтягнеться сама.
2. **Логін застосунку** (неофіційно, працює одразу). Пошта й пароль EcoFlow плюс серійний номер станції. EcoFlow може змінити цей спосіб без попередження.

Станція має бути в Wi-Fi і додана в застосунок EcoFlow. Lumos питає дані раз на 3 хв (поки відкрита картка, частіше). Ключі й пароль зберігаються лише на твоєму ПК, зашифровані ключем користувача Windows, і йдуть тільки на сервери EcoFlow. Перевірено на полях River 2 / River 2 Pro.

## Спільний збирач

Щоб тисячі копій програми не навантажували невеликі сайти обленерго, раз на 5 хвилин GitHub запускає
Lumos у режимі збирача (`.github/workflows/collect.yml`): він обходить сайти Укрзалізниці, Волиньобленерго,
Миколаївобленерго, Telegram-канали Укренерго, ДТЕК та обленерго і кладе результат в один файл —
[`data.json` у гілці `data`](https://github.com/dimasdonetsk/Lumos/blob/data/data.json).

Програма спершу бере дані з цього файлу. Якщо він старший за 20 хвилин, недоступний або в ньому немає
потрібної області, програма сама перевіряє джерела напряму. Що використовується зараз, видно в меню
«Джерела даних».

## Дані

Графіки беруться з відкритого агрегатора
[UA Power Outages Monitor](https://github.com/chaichuk/UA-power-outages-monitor), який оновлюється кожні 5 хвилин.
Останні дані зберігаються локально, тому без інтернету програма показує останній відомий графік.

Налаштування, кеш і журнал помилок лежать у `%AppData%\Lumos`.

| `src/OverlayViewModel.cs` | тексти, кольори, клітинки графіка |
| `src/TrayController.cs` | іконка в треї і чорне меню |
| `src/AppController.cs` | таймери, сповіщення, налаштування |
| `src/Theme.cs` | темна і світла теми |
| `src/Updater.cs`, `src/Program.cs` | інсталятор і автооновлення (Velopack) |
| `src/UzSource.cs` | графіки Укрзалізниці |
| `src/ExtraSources.cs` | Вінницька, Одеська, Дніпропетровська, Миколаївська, Кіровоградська, Волинська області |
| `src/VolynImage.cs` | розпізнавання картинки-графіка Волиньобленерго |
| `tests/` | автотести парсерів (запускаються на GitHub перед кожною збіркою) |
| `src/EmergencyMonitor.cs` | пошук аварійних відключень у Telegram-каналах |
